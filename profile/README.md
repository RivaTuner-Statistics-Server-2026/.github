# Project Overview

RivaTuner Statistics Server (RTSS) is a monitoring, frame-rate control, and on-screen display utility commonly used with gaming and hardware monitoring applications.

It provides tools for displaying performance statistics in games, limiting frame rates, monitoring rendering behavior, and configuring application-specific profiles.

---

# Features

- On-Screen Display support
- FPS monitoring
- Frame-rate limiting
- Application profiles
- Rendering statistics
- OSD positioning
- Custom display settings
- Raster and vector OSD modes
- Profile-based configuration
- Game monitoring
- Frame-time visualization support
- Hardware monitoring integration
- Configurable detection levels
- Screenshot-related workflows
- Lightweight background operation

Available functionality can vary depending on RTSS version, graphics API, game, and integrated monitoring software.

# On-Screen Display

RTSS can display performance information directly over supported games and 3D applications.

Common OSD statistics include:

- Frame rate
- Frame time
- GPU usage
- GPU temperature
- CPU usage
- CPU temperature
- VRAM usage
- RAM usage
- Clock speeds
- Power-related metrics

Some hardware statistics require integration with a compatible monitoring application.

---

# Frame Rate Limiter

The built-in frame limiter can be used to set a maximum frame rate for selected applications.

Frame-rate limiting can be useful for:

- Stabilizing frame pacing
- Reducing unnecessary GPU load
- Managing power consumption
- Controlling thermals
- Matching display targets
- Testing performance

Results depend on the game, rendering API, display configuration, and graphics driver.

---

# Application Profiles

RTSS supports individual profiles that allow settings to be configured for specific applications.

Profiles can control options such as:

- Frame-rate limits
- Application detection
- OSD behavior
- Rendering compatibility
- Display settings
- Statistics presentation

This makes it possible to maintain different configurations for different games and applications.

# Performance

RTSS is designed to operate with relatively low overhead, but overlay behavior and compatibility can vary by application.

For accurate performance comparisons, use consistent graphics settings, frame limits, drivers, background applications, and monitoring configurations.

---

# Troubleshooting

If the OSD does not appear, review application detection settings, profile configuration, monitoring integration, and whether the target application permits third-party overlays.

If a game behaves unexpectedly with RTSS enabled, disable the overlay or application profile and compare behavior before changing additional settings.

Some competitive games and anti-cheat systems may restrict overlay or monitoring functionality.
